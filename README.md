# RAMMP Fork - ROS2 Kinova Kortex

This fork of the Kinova Kortex ROS2 API maintains a custom version of the ROS2 driver for the Kinova Gen3 arms, updated to support the specific requirements for this project.



## Changelog

The `humble-rammp-demo-april-2026` branch is main working branch for this fork. The key changes are the following:

- All dependencies added to `package.xml` instead to simplify install flow for large projects (Installation flow outlined below)

## Installation

To build this codebase, clone it into the `src` directory of your ROS2 workspace and use rosdep to install all dependencies.****
